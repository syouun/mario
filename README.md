# SMB 再現プロジェクト — 1-1 〜 8-4 完結版（最終仕様書は SPEC_FINAL.md）

HTML5 Canvas + バニラ JavaScript。ビルド不要です。

## 起動方法

1. このフォルダ（`smb`）の `index.html` をダブルクリックし、Chrome または Edge で開きます。
2. 左に 256×240 のゲーム画面（整数倍に拡大）、右に検証用の情報パネルが出ます。

`file://` のままで動くよう、ES Modules ではなく通常の `<script>` を順に読み込む構成にしています。
ローカルサーバーを使いたい場合は、このフォルダで `python -m http.server 8000` を実行し、
`http://localhost:8000/` を開いても同じように動きます。

## 操作

キー割り当ては `js/config.js` で変更できます（1 つのボタンに複数キーを割り当て可）。

| ボタン | 既定のキー | 動作 |
| --- | --- | --- |
| 十字 | ← → ↑ ↓ | 左右移動。↓ でしゃがみ（SUPER / FIRE のみ） |
| A | A / X / Space | ジャンプ（押し続けるほど高く跳ぶ） |
| B | B / Z / Shift | ダッシュ（離してから 10 フレームは最高速度を保つ）。FIRE のときは押した瞬間にファイアボール |

| 検証キー | 動作 |
| --- | --- |
| H | 情報パネルの表示切替 |
| G | タイル格子と列番号（黄 = 動画から抽出、赤 = 補完） |
| V | 動画から抽出した背景を半透明で重ねる |
| T | ジャンプ軌跡（黄）と最高到達点（赤線）の表示切替 |
| P / N | 一時停止 / 停止中に 1 フレーム進める |
| 1 / 2 / 3 | 速度 等倍 / 1/2 / 1/4 |
| R | 面の最初からやり直す |
| F | 自由移動（地形を無視して上下左右に動く）切替 |
| M | 形態を SMALL → SUPER → FIRE → SMALL の順に切替（変身演出つき） |
| L | マップ切替（1-1 → 検証用テストマップ → 1-2 → …）。形態は引き継ぐ |
| I | ダメージを受けない（敵の配置や甲羅の確認用）切替 |
| K | わざと被弾する |
| E | 敵の崖の挙動を「原作どおり → 全員折り返す → 全員落ちる」の順に切替 |
| J | 決まった地点へ飛ぶ。1-1: 57 列の土管の手前 → 中間地点 → スターのレンガ手前 → 階段地帯 → 163 列 → ゴール前 → 地下のコイン部屋 / 1-2: 30 列 → 中間地点 → 階段とリフトの手前 → 天井の上（165 列）→ ワープゾーンの上 → 出口の地上 |
| Y | 絵をスプライト画像 ⇔ 図形（プレースホルダ）で切替 |
| O | 消音の切替（音量は `config.js` の `SMB.SOUND.volume`） |
| Enter | 面番号画面を飛ばす |

ゲームパッド（Standard 配置）も使えます。割り当ては `config.js` の `PAD_CONFIG` です。

## ブロック（ステップ5）

| ブロック | SMALL | SUPER / FIRE |
| --- | --- | --- |
| ？（コイン） | コインが飛び出し 200 点、使用済みブロックに | 同じ |
| ？（パワーアップ） | キノコが出る | フラワーが出る |
| レンガ（中身なし） | 揺れるだけ | 壊れて破片 4 個、50 点 |
| レンガ（複数コイン） | 最初に叩いてから約 4 秒は叩くたびにコイン、その後の 1 回で使用済みに | 同じ |
| 隠しブロック | 下から叩いたときだけ出現（横・上からはすり抜ける） | 同じ |

- 叩いたブロックは 8 フレームで 4px 上下に揺れます（揺れの間もブロックは足場として残ります）。
- キノコは右へ 1px/f で動き、壁で反転し、崖から落ちます。触れると 1000 点で変身します。フラワーはその場に留まります。

## 形態としゃがみ（ステップ6）

| 形態 | 高さ | 当たり判定 |
| --- | --- | --- |
| SMALL | 16px | 左右 y+8、頭上 y+2 |
| SUPER / FIRE | 32px | 左右 y+8 と y+24、頭上 y+2 |
| SUPER / FIRE（しゃがみ） | 16px 相当 | 左右 y+24 のみ、頭上 y+18 |

- しゃがみ中は左右入力が効かず、摩擦だけで滑ります。ダッシュから↓を押すと、高さ 1 マスの隙間に滑り込めます。
- しゃがんだままジャンプすると、着地までしゃがみ姿勢を保ちます。
- 低い隙間の中でしゃがみを解くと、左右とも壁に埋まった状態になり、向いている方へ 1px/f ずつ押し出されます。
- 変身演出の間（60 フレーム）はゲーム全体が止まり、マリオの大きさが 4 フレームごとに切り替わります。SUPER と FIRE の間は色だけが点滅します。

## 敵（フェーズ2）

| 敵 | 速さ | 崖（既定） | 踏むと | 甲羅・突き上げで倒すと |
| --- | --- | --- | --- | --- |
| クリボー | 0.5 px/f | 落ちる | 潰れて 30f 後に消える | ひっくり返って落ちる（突き上げ 100 点） |
| 緑ノコノコ | 0.5 px/f | 落ちる | 甲羅になる | 同上（突き上げ 200 点） |
| 赤ノコノコ | 0.5 px/f | 折り返す | 甲羅になる | 同上（突き上げ 200 点） |

- 出現: 配置した列が画面右端の 1 タイル先に入ったときに 1 回だけ出現し、左（マリオ側）へ歩き出します。同時に 5 体まで。
- 消滅: 画面左端から 64px 外に出るか、画面下に落ちると消えます。滑る甲羅は画面右端から 128px 先で消えます。
- 敵どうしがぶつかると互いに向きを変えます。
- 崖の挙動は、配置データの `"edge"` 指定 → `constants.js` の `ENEMY_EDGE_OVERRIDE`（E キーでも切替）→ 種類ごとの既定値（`enemies.js` の `ENEMY_DEFS`）の順で決まります。

### 踏みつけと甲羅

- 踏みつけの条件: マリオが下降中で、足元が敵の当たり判定の上端から 8px 以内（仕様書 1.5）。それ以外の接触は被弾です。
- 踏むと 4px/f で跳ね返り、A を押していれば高く跳びます。着地せずに続けて踏むと 100 → 200 → 400 → 500 → 800 → … → 1UP。
- 止まった甲羅は、横から触れても上から踏んでも、マリオと反対側へ 3px/f で滑り出します（400 点）。蹴った直後の 8f はマリオに当たりません。
- 滑る甲羅は壁で跳ね返り、崖から落ち、触れた敵を倒します（500 → 800 → 1000 → 2000 → … → 1UP）。踏むと止まります。
- 止まった甲羅は約 4 秒で震え始め、約 5 秒でノコノコに戻ります。

### ブロックの突き上げ

敵が立っているブロックを下から叩くと、その敵はひっくり返って落ちます。上にあるキノコは跳ね上がり、マリオから遠い側へ向きを変えます。

## ダメージ・ミス・残機（フェーズ2）

- SUPER / FIRE で被弾すると SMALL に縮み（60f 全体停止）、その後 128f は点滅して敵に当たりません。
- SMALL で被弾するとミス: 全体が 30f 止まり、マリオが上へ跳ねて地形を無視して落ちます。約 3 秒後に残機が 1 減ります。
- 穴に落ちたとき、TIME が 0 になったときもミスです（穴のときは跳ねません）。
- 残機が残っていれば面番号画面（WORLD 1-1 と残機、約 2.5 秒）のあと最初から SMALL で再開します。
  残機 0 で GAME OVER（3 秒）のあと、残機 3・スコア 0 から始め直します。
- 中間地点（1-1 は 82 列）を通過してからミスすると、そこから再開します。

## 土管ワープ

- 57 列の土管の上に立ち（マリオの中心が土管の口の内側）↓ を押すと、1px/f で沈み、入り切ってから地下のコイン部屋に切り替わります。マリオは画面の上から落ちてきます。
- 地下の右下にある横向きの土管に、接地したまま → で押し付けると入り、地上の 163 列の土管から 1px/f でせり上がって出てきます。
- 土管の出入り中は TIME だけが進み、敵は止まります。エリアの状態（使ったブロック、取ったコイン）は面を遊んでいる間は保持されます。

## ゴールとクリア

| 段階 | 内容 |
| --- | --- |
| 掴む | ポールの列（台のブロックを含む）に触れた瞬間。掴んだ足元の高さで 100 / 400 / 800 / 2000 / 5000 点（境界は近似） |
| 降りる | マリオと旗が 2px/f で降り、得点の数字がポールを上っていく。TIME は止まる |
| 城へ | ポールの右側に回って 30f 待ち、城の入口まで歩いて中に入る |
| TIME 加算 | 残り TIME を 1f に 1 ずつ減らし、1 カウント 50 点 |
| 城の旗 | 城の上に旗が上がる |
| 花火 | 掴んだときの TIME の下 1 桁が 1 / 3 / 6 なら、その数だけ花火（1 発 500 点） |
| 次へ | 面データの `next` の面へ（1-1 → 1-2 → 1-3）。形態・スコア・残機は引き継ぐ。まだ作っていない面は「NOT YET BUILT」を出して 1-1 へ戻る |

## パックンフラワー

- 土管の中で 60f 待つ → 24f かけて 24px せり上がる → 60f 出たまま → 24f で引っ込む、を繰り返します（フレーム数は近似）。
- 出てくる直前にマリオの中心が土管の中心から ±24px 以内にいると、出てこずに待ち直します（土管の上に立っていれば出てこない）。
- 踏めません。上からでも横からでも、触れると被弾します。土管の中に隠れている部分には当たり判定がありません。

## スター

- 1-1 では 101 列のレンガ（テストマップでは 9 列）から出ます。せり上がったあと右へ 1px/f で進み、着地するたびに跳ねます。壁では向きを変えます。
- 取ると 1000 点で、`STAR_FRAMES`（480f = 8 秒。ご指定の 400〜500f に合わせた値で、仕様書の近似値は 690f）の間は無敵です。体が 4 色で高速に点滅し、残り 120f で点滅が遅くなります。
- 無敵の間は、触れた敵がすべてひっくり返って倒れます（パックンフラワー・甲羅も）。得点は 100 → 200 → 400 → … と上がり、着地しても連続数は切れません。
- 穴に落ちたとき、時間切れのときはスター中でもミスです。

## ファイアボール

| 項目 | 値 |
| --- | --- |
| 発射 | FIRE のとき B を押した瞬間（しゃがみ中は投げない）。投げるポーズ 8f |
| 同時に出せる数 | 2 個（爆発の演出中も 1 個と数える） |
| 動き | 向いている方へ 4px/f。下向き 3px/f から重力 0.3125 で落ち、床に当たると上向き 3px/f で跳ねる |
| 消える | 壁に当たる（爆発 12f）/ 敵に当たる（爆発、敵は倒れる）/ 画面の外に出る（爆発なし） |
| 得点 | クリボー 100、ノコノコ 200、パックンフラワー 200 |

- 発射位置・初速・重力・跳ねる高さは近似値です（`constants.js` の `FIREBALL_*`）。
- フラワーは SUPER / FIRE のときに？ブロックのパワーアップから出ます。M キーでも FIRE にできます。

## サウンド

最初のキー入力（またはクリック）で音が出始めます（ブラウザの決まりで、それまでは鳴らせません）。情報パネルの「音」の行に、合成の方式・いま鳴っている曲・効果音・各チャンネルを BGM と SE のどちらが使っているかが出ます。

### 仕組み（仕様書 5 章）

- `audio.js` の合成部が、パルス波 2 本（デューティ 12.5 / 25 / 50 / 75%、音量 16 段階）・32 段の階段状の三角波・15bit LFSR のノイズを 1 サンプルずつ作り、実機と同じ非線形ミキサーと出力フィルタ（90Hz / 440Hz のハイパス、14kHz のローパス）を通します。
- 合成は AudioWorklet で動かします（`file://` でも読めるよう data URL で読み込み）。使えない環境では ScriptProcessor で同じ合成部を動かします。
- シーケンサはゲームの 1 フレームごと（60Hz）に進みます。一時停止中は音が止まり、スロー再生中は曲もゆっくりになります。

### 効果音が鳴っているチャンネルの BGM は消える（仕様書 5.3）

| チャンネル | 効果音 |
| --- | --- |
| パルス 1 | ジャンプ（チビ / スーパー）、踏みつけ、蹴る・倒す、固いものを叩く、ファイアボール、土管・被弾、旗が降りる |
| パルス 2 | コイン、アイテムが出る、パワーアップ、1UP、TIME の得点化の「ピッ」 |
| ノイズ | レンガが壊れる、ファイアボールが弾ける、花火 |

- 各チャンネルは「BGM の声」と「SE の声」を持ち、SE が鳴っている間はそのチャンネルだけ SE に置き換わります。BGM は消えている間も進んでいるので、SE が終わると曲のその時点から戻ります。
- 同じチャンネルで SE が重なったら、優先度の高い方（同じなら新しい方）が鳴ります（`sounds.js` の `priority`）。
- ジングル（ミス・コースクリア・ゲームオーバー・残り時間警告）は全チャンネルを使い、鳴っている間は SE を受け付けません。ゴールでは、コースクリアのジングルが終わってから TIME の得点化が始まります。

### BGM を耳コピデータに差し替える

`music/` の各ファイルの `channels` を書き換えるだけです（ファイル名や `id` はそのまま）。形式は仕様書 5.2 のとおりで、次の 2 通りの書き方ができます。

```js
// 短縮記法（文字列）: 音名:長さ（フレーム）、r:休符、k s h t:ノイズの打楽器（キック・スネア・ハット・金属）
//   @d2 = デューティ 0〜3、@v10 = 音量 0〜15、@e:pluck = 音量の形（hold / stac / pluck / swell）
//   [ ... ]x4 = 繰り返し、| は小節線（読み飛ばす）
pulse1: '@d2 @v10 @e:pluck E5:10 G5:10 C6:20 | [A5:5 G5:5]x2 r:20',

// 配列（JSON）
pulse1: [{ note: 'E5', len: 10, duty: 2, vol: 10, env: 'pluck' }, { rest: 10 }],
noise:  [{ drum: 'h', len: 10 }],
```

- 長さはフレーム数です（60 フレーム = 1 秒）。テンポ 150 なら 4 分音符 = 24 フレーム。
- 4 チャンネルの合計の長さを揃えてください（揃っていないとループのたびにずれていきます）。
- `loopFrom` でループの戻り先、`defaults` でチャンネルごとのデューティ・音量・音量の形の既定値を指定できます。
- 今入っている曲・ジングル・効果音は、すべてこのプロジェクト用に作ったオリジナルの仮のものです。

- 触れると**ミス**（沈んで消える）。表面と内側を別の絵で描き、表面は波打ちます。ふだんの穴と違い、画面の下まで落ちなくても即ミスです。

- 中心のタイルの中心を軸に、**火の玉 6 個（8px おき）**が一列に並んで回ります。回転は動画の実測で **約 1.85°/フレーム**（1 周およそ 195 フレーム）。向きは `dir`（1 = 時計回り / -1 = 反時計回り）、初期角は `angle`（度）。

### 水中の物理（エリアの `water: true`）
- **A を押すたびにひと漕ぎ**（上向き 1.5px/f）。押し続けると上昇が少し伸びます。何もしないとゆっくり沈みます（落下の上限 1.5px/f）。連打で上昇。
- 横の最高速度は **約 1.06px/f**（地上の歩きより遅い）。入力を離すと地上よりゆっくり止まります。底に足がつけば歩けます。数値は `constants.js` の `SWIM`・`WATER_WALK_MAX`・`SWIM_*`。

### 最終決戦: 大魔王クッパ・橋の崩落・エンディング
- **大魔王の挙動（`bowser`）**:
  - 橋（32〜44 列）の上でマリオの方を向きながら前後にステップ移動し、一定間隔で高くジャンプします（ジャンプの最高点では橋との間に約 36px の隙間ができ、大マリオでも下をくぐり抜けられます）。

  - **無数のハンマー連投（`hammer`）**: 6 発 1 組の山なり軌道のハンマーを高速で連投します（`BOWSER_VOLLEY_*`）。
  - **撃破方法**:
    1. **斧に触れて橋を落とす**: 橋の右端（45 列 8 行）の斧に触れると、画面上の弾が消えて全体が静止し、まず鎖（44 列 9 行の `/`）が切れ、続いて橋が右端（44 列）から左端（32 列）まで **4 フレームおき**（動画で実測）に 1 マスずつカタカタと音を立てて崩れ落ちます。橋が消え切ると、クッパが咆哮とともに溶岩へ落下します。
    2. **ファイアボールを規定数当てる**: ファイアボールを **5 発**（`BOWSER_HP`）当てると、5000 点が入ってクッパがその場でひっくり返り、溶岩へ落ちていきます。
